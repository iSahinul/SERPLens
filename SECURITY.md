# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.
Use GitHub's private vulnerability reporting on this repository
(the **Security** tab → **Report a vulnerability**), or open a regular
issue saying only that you need a private channel — no details in public.

You can expect an acknowledgement within a few days. This is a small
open-source project maintained by one person; fixes ship as fast as
they reasonably can.

## Scope notes

- This project never asks for your passwords or account credentials.
- Anything that needs a key or a login uses **your own** credentials,
  stored on **your** machine. If you find a place where the code sends
  data somewhere unexpected, that is exactly the kind of report wanted.
